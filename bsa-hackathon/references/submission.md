# Submission and Demo

Check `event.md` for the platform, the deadline, and required items. This checklist adds the common items.

## Repository

- Public repository, unless the rules say otherwise.
- No secrets in the code or the git history (see `security.md`).
- The project builds from a clean clone with the steps in the README.

## README

- Problem: what problem the project solves, and for whom.
- Solution: what the project does.
- Architecture: contracts, front end, and other parts, and how they connect.
- How to run: exact steps.
- Deployed contracts: address and block explorer link for each.
- Team: names and roles.

## Demo

- Show the main flow working, not slides about it.
- Record a backup video in case the live demo fails.
- Practice the demo with a timer.

## Pitch

1. Problem
2. Solution and demo
3. Why it needs a blockchain
4. What is next

## Before the Deadline

- Submit early. Update the submission later if the platform allows it.
- Check that every link works from a private browser window.
